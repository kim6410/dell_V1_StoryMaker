## 변경 내용

### 1. MP4 생성 직후 자동 저장

`makeVideo()`에서 브라우저 MP4 렌더 완료 후 `saveCurrentToArchive()`를 즉시 실행하도록 변경했다.

자동 저장이 성공해야 최종 진행률 100%와 제작 완료 상태를 표시한다.

자동 저장이 실패하면 성공으로 위장하지 않고 제작 실패 메시지로 처리한다.

### 2. Play·Stop 동작 단순화

Play 버튼은 최종 MP4 재생만 담당한다.

Stop 버튼은 최종 MP4 정지와 장면 미리보기 정지만 담당한다.

두 버튼에서 보관함 저장 호출을 제거했다.

### 3. 보관함 바로가기 직접 이동

MP4 하단 보관함 바로가기와 썸네일 하단 보관함 바로가기를 동일한 `openArchive()` 함수에 연결했다.

클릭 시 저장 상태·저장 중 플래그·대기 플래그를 검사하지 않고 바로 `/beta/archive`로 이동한다.

### 4. 복잡한 이동 대기 상태 제거

`pendingArchiveOpen` 상태와 저장 완료 후 이동 예약 로직을 제거했다.

저장과 이동의 책임을 분리해 버튼 충돌 가능성을 줄였다.

### 5. 브라우저 캐시 버전 갱신

production.html의 beta-shortform-inline.js 쿼리 버전을 아래 값으로 변경했다.

`20260725-auto-save-direct-archive-1`
