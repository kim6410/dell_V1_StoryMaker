## 3. 연구실 카드 연결 조사

대시보드 중앙의 `AI 연구실` 카드는 기존 좌측 `체험 연구실` 메뉴가 열던 화면으로 연결해야 했다.

`네모트론 연구실` 카드는 서버에 이미 만들어 둔 네모트론 테스트 화면으로 연결해야 했다.

초기에는 URL 이동 방식으로 연결했으나 실제 기존 기능과 맞지 않았다.

AI 연구실이 모바일 WebGPU·WASM TTS 비교 화면으로 열렸고, 네모트론은 별도 라우팅만으로 정상 표시되지 않았다.

그래서 URL을 추측하는 방식을 중단하고 V1 구현을 직접 확인했다.

다만 WebGPU 실패 시 FFmpeg WASM으로 전환되는 완성형 대체 경로는 확인되지 않았다.

현재 판정:

- `/slideshow` 실제 WebGPU: 브라우저 제작 경로에 적용
- `/slideshow` 실제 WASM 영상 렌더: 확인되지 않음
- 실패 시: 기존 서버 제작 경로 사용에 가까움

## 12. V2 엔진 이식 공사 규모 판단

V2에 이미 WebGPU·WASM 엔진이 있으므로 새 엔진 개발은 필요하지 않다.

핵심은 독립 `/podcast`와 `/slideshow` 화면에 V2의 실제 호출 흐름을 브리지로 연결하는 것이다.

슬라이드쇼는 이미 브라우저 렌더러가 붙어 있어 작은 공사에서 중간 공사 수준이다.

팟캐스트는 V2 Worker가 완성형으로 실제 작동한다면 중간 규모의 브리지 작업이다.

필요한 작업:

- V2 Worker 로드
- 현재 화면 입력값을 Worker 입력 형식으로 변환
- 진행률 연결
- MP3·SRT 결과 연결
- 배경음악 및 화자 순서 처리 확인
- 서버 업로드와 보관함 저장
- 실패 시 기존 Supertonic 복귀

권장 fallback:

1. WebGPU
2. WASM
3. 기존 서버 Supertonic 또는 FFmpeg

기존 서버 제작 경로를 삭제하지 않고 병렬로 붙여야 한다.
