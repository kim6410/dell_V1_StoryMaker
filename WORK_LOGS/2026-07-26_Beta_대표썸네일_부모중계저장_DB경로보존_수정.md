## 추가로 발견한 구조 문제

`beta_jobs.result_json` 컬럼은 JSON 본문이 아니라 작업의 `result.json` 파일 경로를 보관합니다.

기존 선택 저장 API는 이 컬럼을 JSON 문자열로 덮어쓰도록 구현되어 있어, 실제 저장이 성공할 경우 기존 보관함 조회 구조를 훼손할 수 있었습니다.

## 수정 내용

### 1. 부모 화면 중계 저장

썸네일 iframe이 직접 `/beta-api`를 호출하지 않습니다.

- iframe이 선택 PNG를 ArrayBuffer로 변환
- `storymaker:thumbnail-save-request` 메시지를 상위 Beta 제작 화면에 전달
- 상위 화면이 로그인 세션으로 설정 저장 및 PNG 업로드 수행
- 서버 선택 정보와 실제 대표 PNG를 다시 조회
- 실제 저장 파일 크기까지 일치할 때만 iframe으로 성공 응답 반환

### 2. iframe 성공 조건 강화

- 부모 저장 응답의 `ok=true` 필수
- 선택 template ID 일치 필수
- 서버 파일 크기 0보다 큼
- 성공 문구에 실제 저장 바이트 수 표시

### 3. DB result_json 경로 보존

기존:

`UPDATE beta_jobs SET result_json=?, selected_thumbnail_template=?, selected_thumbnail_path=?`

수정:

`UPDATE beta_jobs SET selected_thumbnail_template=?, selected_thumbnail_path=?`

따라서 DB의 기존 `result_json` 파일 경로는 유지됩니다.

### 4. 캐시 버전

`v=20260726-confirm-save-4`
