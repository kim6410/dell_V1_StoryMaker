## 증상

- 대표 썸네일 선택 버튼을 눌러도 선택된 느낌이 약함
- 실제 사용자 클릭 시 Beta 서비스 로그에 썸네일 저장 POST 요청이 기록되지 않음
- 보관함에 선택한 대표 썸네일이 표시되지 않음
- 동일 iframe URL 캐시로 이전 JavaScript가 남았을 가능성 존재

## 조치

1. 대표 썸네일 선택 버튼을 기존 대비 약 2배 크게 변경
2. 버튼을 카드 전체 폭으로 배치하고 그라데이션·그림자·호버 효과 적용
3. 개별 버튼 이벤트 대신 `verticalGrid` 이벤트 위임 방식 적용
4. 버튼 클릭 즉시 선택 후보 카드에 노란색 강조 표시
5. 화면 내부 확인 모달 추가
   - 문구: `저장하시겠습니까?`
   - 버튼: `예`, `아니오`
6. `아니오` 선택 시 서버 요청 없이 선택 취소
7. `예` 선택 시에만 PNG 생성 및 서버 업로드
8. 저장 완료 후 다음 두 항목을 서버에서 재검증
   - `/thumbnail-studio`의 `selected_template_id`
   - `/file/thumbnail` 실제 PNG 파일 및 파일 크기
9. 서버 재검증까지 통과해야 초록색 `대표 썸네일 저장 완료` 표시
10. iframe URL에 `v=20260726-confirm-save-1`을 추가해 브라우저 캐시 우회
