# StoryMaker Beta 대표 썸네일 실제 서버 저장 재검증 보강

작성일: 2026-07-26

## 증상

- 화면에서는 `대표 썸네일 저장 완료`로 표시됨
- 실제 작업 `beta_20260726_191848_6c7a97`에는 썸네일 파일이 없음
- DB `selected_thumbnail_template`, `selected_thumbnail_path`가 NULL
- `result.json`의 `assets.thumbnail`도 NULL
- Beta 서비스 로그에 실제 썸네일 저장 POST 요청이 없음

## 원인 판단

- iframe 내부 저장 요청이 실제 로그인 세션을 가진 최상위 V1 화면을 통해 전달되지 않았을 가능성
- 브라우저 성공 표시와 서버 저장 상태가 분리된 거짓 양성 가능성

## 수정

1. `authFetch()` 추가
   - 우선 `window.top.fetch()` 사용
   - 최상위 V1 로그인 세션과 credentials 포함
   - 접근 불가 시 iframe 자체 fetch로 폴백
2. 편집 설정 저장, PNG 업로드, 서버 상태 확인, 대표 파일 확인을 모두 `authFetch()`로 통일
3. PNG 업로드 응답 검증 강화
   - `ok=true`
   - 응답 template_id 일치
   - 응답 size가 0보다 큼
4. 서버 재검증 강화
   - selected_template_id 일치
   - files 목록에 선택 템플릿 존재
   - `/file/thumbnail` HTTP 성공
   - 실제 파일 Blob 크기 확인
5. 업로드 응답 크기와 재다운로드 파일 크기가 정확히 같아야 성공 처리
6. 성공 문구에 실제 서버 파일 크기를 표시
   - 예: `Badge Focus 저장 완료 · 482,316 bytes · 보관함 반영 확인`
7. iframe 캐시 버전을 `v=20260726-confirm-save-3`으로 변경
