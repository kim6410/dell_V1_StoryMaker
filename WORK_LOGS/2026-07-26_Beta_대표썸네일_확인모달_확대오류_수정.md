# StoryMaker Beta 대표 썸네일 확인 모달 확대 오류 수정

작성일: 2026-07-26

## 증상

- 대표 썸네일 선택 후 확인 모달의 미리보기 Canvas가 화면 전체를 덮음
- `저장하시겠습니까?`, `예`, `아니오` 버튼이 이미지 뒤에 가려짐
- 실제 `예` 클릭이 불가능하여 서버 저장 POST 요청이 발생하지 않음
- 보관함 대표 썸네일이 저장되지 않음

## 실제 확인 작업

- 작업 ID: `beta_20260726_191848_6c7a97`
- `result.json assets.thumbnail`: `None`
- DB `selected_thumbnail_template`: `None`
- DB `selected_thumbnail_path`: `None`
- 해당 작업의 썸네일 저장 POST 로그: 없음

## 원인

모달 미리보기용으로 기존 카드 Canvas를 `cloneNode()`로 복제했습니다. 복제 Canvas가 `.preview-canvas`의 `position:absolute; inset:0; width:100%; height:100%` 스타일을 그대로 적용받아 모달 영역 전체를 덮었습니다.

## 수정

1. 확인 모달의 이미지 미리보기 요소 완전 제거
2. Canvas 복제 및 `drawImage()` 코드 제거
3. 모달은 다음 요소만 표시
   - `저장하시겠습니까?`
   - `아니오`
   - `예`
4. iframe 캐시 버전 갱신
   - `v=20260726-confirm-save-2`
5. 기존 저장 검증 유지
   - 선택 템플릿 ID 재조회
   - 실제 `/file/thumbnail` PNG 파일 확인
