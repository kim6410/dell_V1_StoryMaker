# StoryMaker Beta 저사양 PC MP4 서버 폴백 최소 수정 업무일지

작성일: 2026-07-26

## 작업 목적

WebGPU를 사용할 수 없는 저사양 PC에서 브라우저 MP4 인코딩이 120초를 초과하면 제작이 오류로 종료되는 문제를 완화하고, 기존 Dell 서버 렌더 API로 자동 전환하도록 최소 수정했습니다.

## 안전 조치

수정 전 공식 백업을 생성했습니다.

백업 경로:

`/home/bourne/StoryMaker_1/Backup/20260726_231500_mp4_timeout_fallback_before`

백업 파일:

- `beta-browser-render.js`
- `beta-shortform-inline.js`
- `production.html`
- `SHA256_BEFORE.txt`
- `SHA256_AFTER.txt`

## 수정 파일

- `StoryMaker_beta/static/beta-shortform-inline.js`
- `StoryMaker_beta/static/production.html`

## 변경 내용

브라우저 MP4 제작이 실패하면 오류로 즉시 끝내지 않고 다음 순서로 처리합니다.

1. 브라우저 MP4 실패 로그 기록
2. Dell 서버의 기존 `/beta-api/jobs/{job_id}/render` API 호출
3. 서버 렌더 완료 후 작업 정보를 다시 불러옴
4. 최종 MP4를 미리보기 영상에 연결
5. 보관함 자동 저장 완료 상태 표시
6. `storymaker:shortform-complete` 이벤트 전송

브라우저 캐시 갱신을 위해 `beta-shortform-inline.js` 버전을 다음으로 변경했습니다.

`20260726-mp4-server-fallback-1`

## 검증 결과

- `node --check beta-shortform-inline.js` 통과
- `python3 -m py_compile beta_jobs.py` 통과
- `storymaker-beta.service` 재시작 후 active
- 운영 페이지 HTTP 200 확인

## 미확인 항목

실제 저사양 원격 PC에서 브라우저 MP4 120초 초과 후 Dell 서버 렌더가 끝까지 완료되고 최종 MP4가 화면과 보관함에 연결되는 E2E는 사용자의 재시험이 필요합니다.

## 롤백

백업 폴더의 다음 파일을 원래 위치로 복원합니다.

- `beta-shortform-inline.js` → `StoryMaker_beta/static/beta-shortform-inline.js`
- `production.html` → `StoryMaker_beta/static/production.html`

복원 후 `storymaker-beta.service`를 재시작합니다.
