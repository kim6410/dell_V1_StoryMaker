## 8. Docker 네트워크 연결 문제와 해결

초기 증상:

V1 백엔드 컨테이너에서 `127.0.0.1:8010` 호출 시 연결 거부 발생.

원인:

컨테이너 안의 `127.0.0.1`은 Dell 호스트가 아니라 해당 컨테이너 자체를 가리킨다.

확인된 V1 Docker 게이트웨이:

`172.27.0.1`

조치:

- Weather Server 호출 주소를 Docker 게이트웨이 기준으로 변경
- UFW에서 V1 Docker 대역만 Weather Server 8010 접근 허용

허용 범위:

```text
출발지: 172.27.0.0/16
목적 포트: 8010/tcp
용도: StoryMaker V1 네모트론 날씨 조회
```

인터넷 전체에 8010 포트를 개방하지 않았다.


## 9. 사용자 DB 지역 연동

사용자 DB 모델 확인:

`/home/bourne/StoryMaker_1/storymaker-web/backend/app/db/models.py`

날씨 기본 지역에 사용하는 필드:

`user_personas.region`

조회 대상:

현재 로그인 사용자의 기본 페르소나를 우선하며, 최근 수정 페르소나 순으로 조회한다.

적용 우선순위:

```text
1. 사용자 질문에 지역명이 명시되면 질문 지역 우선
2. 질문에 지역이 없으면 로그인 사용자 DB의 user_personas.region 사용
3. DB 지역도 없으면 Weather Server 기본 위치 사용
```

예시:

```text
DB 지역: 경기도 남양주시
질문: 오늘 날씨 알려줘
결과: 경기도 남양주시 기준
```

```text
DB 지역: 경기도 남양주시
질문: 서울 오늘 날씨 알려줘
결과: 서울 기준
```
