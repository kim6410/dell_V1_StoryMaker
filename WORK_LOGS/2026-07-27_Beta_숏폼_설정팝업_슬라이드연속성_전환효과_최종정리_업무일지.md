## 2. 최종 완료 내용

### 2.1 슬라이드 움직임 완화

- 화면 전체가 강하게 밀리는 슬라이드 이동을 약한 이동으로 축소했다.
- 좌우 이동은 화면 폭의 약 8% 수준으로 제한했다.
- 상하 이동은 화면 높이의 약 6% 수준으로 제한했다.
- 이미지 내부 확대·좌우·상하 Ken Burns 강도를 기존보다 크게 낮췄다.
- 멀미를 유발하던 강한 이동과 과도한 확대를 제거했다.

### 2.2 한 장 이미지 내부 끊김 제거

- 한 장 이미지가 표시되는 동안 두 번씩 툭거리던 현상을 수정했다.
- `sin()` 기반 왕복 상하 이동을 제거하고 한 방향의 단조 증가 움직임으로 변경했다.
- 이미지 진행값에 5차 smootherstep 가감속을 적용했다.
- 이전 이미지와 현재 이미지의 카메라 진행값을 분리했다.
- 전환 중 진행값이 1.0까지 갔다가 다시 약 0.6으로 후퇴하던 경로를 제거했다.
- 프레임 진행값이 시작부터 끝까지 되돌아가지 않고 연속적으로 증가하도록 수정했다.

### 2.3 전환 시간과 사용자 설정 저장

- 기본 전환 시간을 2.20초로 정리했다.
- 사용 가능 범위는 0.50초부터 4.00초다.
- 설정 변경 후 약 0.8초 뒤 사용자별 설정 API에 자동 저장된다.
- 다음 접속과 다음 제작에서 사용자가 저장한 값을 그대로 복원한다.
- 과거 0.75초·1.55초 값을 강제로 2.20초로 변환하던 화면 복원 코드를 제거했다.
- 사용자가 직접 선택한 값은 더 이상 강제로 덮어쓰지 않는다.

### 2.4 최대 8장 랜덤 이미지 사용

- 사용 이미지가 8장 이하이면 모두 사용한다.
- 사용 이미지가 9장 이상이면 무작위로 최대 8장만 선택한다.
- 전체 이미지를 모두 내려받은 뒤 버리는 방식이 아니라 처음부터 선택된 8장만 불러오도록 변경했다.
- 선택된 이미지는 영상 길이에 맞게 반복 배치한다.

### 2.5 설정 아코디언을 팝업으로 전환

- 제작 본문에 노출되던 음성·워터마크·영상·음악·자막 아코디언을 제거했다.
- `숏폼/숏츠 제작` 헤더에 `⚙ 설정` 버튼을 추가했다.
- 기존 설정 DOM을 복제하지 않고 팝업 내부로 실제 이동시켰다.
- 팝업 안에서는 모든 설정 항목이 한 번에 펼쳐져 표시된다.
- 팝업 바깥 클릭, ESC, 오른쪽 위 `×`, 하단 `설정 완료`로 닫을 수 있다.
- 팝업을 닫아도 입력값과 파일 선택 상태가 유지된다.
- 기존 사용자별 자동 저장과 설정값 복원 흐름을 그대로 유지했다.
- 설정 팝업의 헤더·카드·입력창·간격·하단 여백을 압축해 전체 높이를 약 30% 줄였다.
- PC에서는 2열, 좁은 화면에서는 1열로 표시한다.

### 2.6 헤더 버튼 정렬

- `⚙ 설정`과 `5 영상 만들기` 버튼을 하나의 버튼 그룹으로 묶었다.
- 숏폼 제작 헤더 가운데에 정렬되도록 그리드 구조를 적용했다.
- 좁은 화면에서는 다음 줄 가운데로 내려가도록 반응형 처리했다.

### 2.7 화면 전환 효과 다양화

자동 랜덤에 등록된 효과:

- 왼쪽 이동
- 오른쪽 이동
- 위로 이동
- 아래로 이동
- 페이드
- 줌
- 와이프

기존 해시 선택식은 짧은 영상의 첫 8개 전환에서 이동 계열이 과도하게 반복됐다.
자동 랜덤의 첫 7번 전환에서 7개 효과가 각각 한 번씩 나오도록 순환 공식을 변경했다.

설정 화면에는 다음 직접 선택 옵션을 추가했다.

- 자동 랜덤
- 왼쪽 이동
- 오른쪽 이동
- 위로 이동
- 아래로 이동
- 페이드
- 줌
- 와이프

직접 선택한 효과는 사용자 설정으로 자동 저장되고 다음 제작에도 유지된다.

### 2.8 MP4 하단 상호·전화번호 표시

- 상호명은 기존 노란색과 검은 외곽선을 유지한다.
- 전화번호는 노란색에서 흰색으로 변경했다.
- 전화번호는 사용자 설정 크기보다 2px 작게 최종 MP4에 렌더링한다.
- 전화번호의 검은 외곽선은 유지한다.
