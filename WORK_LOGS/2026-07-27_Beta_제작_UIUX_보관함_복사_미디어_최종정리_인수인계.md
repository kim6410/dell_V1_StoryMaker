## 6. 보관함 SNS 8채널 복사 개선

### 복사 방식

- 단순 텍스트 복사 대신 HTML과 일반 텍스트를 함께 Clipboard에 기록.
- 블로그는 제목·소제목·문단·굵은 글씨 등 네이버 블로그 붙여넣기용 서식 유지.
- 블로그 제외 채널은 마크다운 `**`, `__`, 백틱, 제목 기호 등을 제거.
- 한 줄은 약 24자 기준으로 단어 단위 줄바꿈.
- 블로그 포함 모든 채널에서 마침표·물음표·느낌표 뒤 빈 줄 추가.
- 복사 후 바로 SNS 입력창에 붙여넣기 쉬운 모바일 가독성 형식으로 정리.

### 팟캐스트 50 정리

- 딸깍 제작 화면의 팟캐스트 50 입력창에서 `**` 제거.
- 영상 제작 요청에 전달되는 대본에서도 `**` 제거.
- 백엔드 Supertonic 음성 제작 단계에서도 한 번 더 제거.
- TTS 대본과 자막에 별표가 따라붙지 않도록 방어적으로 처리.

### 화면 가독성

- 블로그 제외 7개 채널은 어두운 보관함 배경에서 밝은 흰색 글씨로 강제 표시.
- 블로그는 흰 배경·검은 글씨 유지.
- 화면용 색상 수정은 복사되는 콘텐츠의 `color:#222` 형식에 영향을 주지 않는다.

### 복사 버튼 UI

- `복사` 버튼을 `SNS 8채널` 제목 바로 오른쪽으로 이동.
- 기존보다 약 20% 확대.
- 청록색 단색 그라데이션, 두꺼운 외곽선, 광택 효과 적용.
- 알록달록한 8개 채널 탭 색상은 사용자가 멋지다고 평가해 현재 디자인 유지.

## 7. 보관함 미디어 미리보기 개선

### 업로드 이미지

- 업로드 이미지 클릭 시 새창 대신 카드형 모달 표시.
- 한 장만 표시하지 않고 해당 작업의 전체 이미지가 갤러리로 표시됨.
- 갤러리 팝업 안에서 세로 스크롤로 전체 이미지 확인.
- 하단 `다운로드` 버튼으로 해당 작업의 이미지 전체 ZIP 다운로드.
- V1 인증 프록시에서 일반 `<a download>`가 불안정해 `fetch → Blob → 브라우저 저장` 방식으로 변경.

### 썸네일과 MP4

- 썸네일 클릭 시 카드형 큰 미리보기 모달.
- MP4 클릭 시 같은 형태의 모달 안에서 영상 재생.
- 새 브라우저 창 열기 제거.
- 기존 `MP4 크게 보기` 별도 버튼 제거.
- 각 미디어 카드의 버튼명을 모두 `다운로드`로 통일.
- 이미지·MP3·썸네일·MP4 버튼은 해당 섹션 자료만 다운로드.
- 하단 전체 ZIP 버튼은 이미지·MP3·SRT·썸네일·MP4 전체 패키지 유지.

### 이미지 전용 API

- `/beta-api/browser/jobs/{beta_job_id}/images-download`

## 8. 다운로드 이미지 워터마크 개선

### 적용 범위

- 원본 업로드 이미지는 변경하지 않음.
- 보관함 이미지 ZIP 및 전체 패키지에 넣는 가공 이미지에만 적용.

### 디자인

- 청록색·노란색 이중 테두리 유지.
- 하단 반투명 검은 패널 적용.
- 상호명은 노란색.
- 전화번호는 흰색.
- 검은 외곽선과 우측·하단 그림자 적용.
- Linux Noto Sans CJK 글꼴 사용 가능하도록 경로 보강.

### 반응형 기준

- 고정 4배 확대는 과도해 취소.
- 세로형·가로형 방향을 구분해 폰트와 패널 높이 자동 조정.
- 세로형 기준 패널 약 17%, 텍스트 최대 폭 약 84%.
- 가로형 기준 패널 약 20%, 텍스트 최대 폭 약 86%.
- 긴 상호명은 이미지 너비에 맞춰 자동 축소.

### 추가 미세조정 요청

사용자가 마지막으로 다음 값을 요청했다.

- 세로형: 텍스트 묶음을 약 0.6cm 위로 이동, 전화번호 폰트 크기 `-3`.
- 가로형: 텍스트 묶음을 약 0.6cm 위로 이동, 전화번호 폰트 크기 `-6`.

이 요청은 이전 응답에서 수정 방향만 설명된 이력이 있으므로, 다음 채팅에서 실제 코드 적용 여부를 반드시 먼저 확인해야 한다.
