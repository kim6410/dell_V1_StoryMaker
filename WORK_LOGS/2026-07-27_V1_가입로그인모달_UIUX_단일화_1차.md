작성일: 2026-07-27
작업 루트: /home/bourne/StoryMaker_1

## 목표
사용자가 직접 보는 V1 가입·로그인 경험을 우선 개선한다. WordPress 관리자 Application Password 복구는 후순위로 두고, 로그인·회원가입·비밀번호 찾기를 하나의 V1 전용 모달에서 일관되게 제공한다.

## 수정 파일

- storymaker-web/backend/app/static/v1/index.html

## 변경 내용
1. auth_modal_unified.js를 V1 인증 모달의 단일 소유자로 고정
2. window.StoryMakerV1AuthModal 네임스페이스를 노출하고 app_auth.js가 해당 소유자에게 위임하도록 변경
3. app_auth.js의 중복 모달 생성 경로 차단
4. handleLogin()의 WordPress 외부 로그인 페이지 이동 제거, V1 통합 로그인 모달 열기로 변경
5. 회원가입 입력을 사용자명·이메일·비밀번호 3개로 축소
6. 비밀번호 확인 입력 제거
7. 아이디 찾기 링크 제거, 이메일 또는 사용자명 로그인 안내로 단순화
8. 비밀번호 찾기는 입력 이메일을 WordPress 공식 lostpassword 경로로 전달
9. V1 CSS 로더가 공용 CSS가 아닌 /static/v1/auth/auth_modal_unified.css를 사용하도록 수정
10. index.html 캐시 버전을 20260727-v1-auth-ux-2로 변경
