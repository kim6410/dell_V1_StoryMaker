## 적용 내용

### 공통 키워드 5칸 편집기

- 기존 React 키워드 입력은 저장 연결용으로 DOM에 유지한다.
- 사용자에게는 `핵심 키워드 1`부터 `핵심 키워드 5`까지 5개 입력칸을 표시한다.
- 기존 쉼표 구분 값은 최대 5개로 분리해 각 칸에 채운다.
- 빈 칸은 저장 문자열에서 제외한다.
- 각 값의 앞뒤 공백은 제거한다.
- Enter 입력 시 다음 키워드 칸으로 이동한다.
- 다섯 번째 칸에서 Enter를 누르면 키워드 영역 입력을 마친다.

### React 상태 동기화

- 타이핑 도중에는 커스텀 입력칸을 유지해 포커스가 끊기지 않도록 한다.
- 키워드 영역에서 포커스가 빠져나올 때 기존 React 입력값으로 합친다.
- 폼 제출 직전에도 동기화를 한 번 더 수행한다.
- 실제 저장은 기존 React 핸들러와 기존 API가 그대로 담당한다.
