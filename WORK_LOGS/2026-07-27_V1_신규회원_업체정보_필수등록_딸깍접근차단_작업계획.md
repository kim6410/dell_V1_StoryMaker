## 사용자 요청

신규 가입 사용자의 마이페이지에 업체 데이터가 없거나 필수 정보가 완성되지 않은 경우, 딸깍 제작을 바로 사용할 수 없도록 한다.

딸깍 제작 메뉴를 누를 때 안내 팝업을 표시한 뒤 `업체 정보` 화면으로 강제 이동하고 업체 등록 폼을 보여준다.

업체정보 화면의 제목은 다음 문구로 통일한다.

`업체 등록 / 수정`

`신규 업체 저장`이라는 별도 제목 문구는 표시하지 않는다.

## 필수 입력 항목

다음 5개 항목의 라벨 앞에 `*`를 표시한다.

- `* 업체명`
- `* 지역`
- `* 전화번호`
- `* 핵심 키워드`
- `* 페르소나 상세 설명`

다섯 항목 중 하나라도 비어 있으면 저장을 차단하고 누락 항목을 안내한다.

## 딸깍 제작 접근 조건

로그인하지 않은 사용자는 기존 로그인 안내를 유지한다.

로그인한 사용자에게 등록된 업체정보가 없거나 다음 필수값 중 하나라도 비어 있으면 딸깍 제작 진입을 차단한다.

- company_name
- region
- phone_number
- keywords 1개 이상
- content 10자 이상

안내 팝업 확인 후 좌측 `업체 정보` 메뉴를 열고 신규 등록 상태가 보이도록 한다.

완성된 업체정보가 하나 이상 있으면 기존 딸깍 제작 흐름을 그대로 유지한다.

## 예상 수정 대상

1. `storymaker-web/backend/app/static/v1/creation-access-guard.js`
   - 업체 목록 API 실시간 조회
   - 딸깍 제작 클릭 차단
   - 누락 항목 안내
   - 업체 정보 화면 이동

2. `storymaker-web/backend/app/static/v1/v1-company-info-ui-tune.js`
   - 화면 제목 `업체 등록 / 수정`
   - 필수 항목 `*` 표시
   - 필수값 저장 전 검증

3. `storymaker-web/backend/app/static/v1/index.html`
   - 보호 스크립트 연결 및 캐시 버전 갱신

4. `storymaker-web/backend/app/api/personas.py`
   - 빈 업체명·지역 자동 대체 제거
   - 업체명·지역·전화번호·핵심 키워드·페르소나 상세 설명 서버 필수 검증

## 안전 원칙

- 수정 전 대상 파일별 백업 생성
- 전체 파일 덮어쓰기 금지
- 정확한 블록만 최소 치환
- 기존 로그인·관리자·업체 선택·딸깍 제작 정상 흐름 유지
- 다른 미커밋 파일을 커밋에 혼합하지 않음
- 수정 후 JavaScript 문법, HTTP 200, 신규 사용자·기존 사용자 양쪽 흐름 검증

## 현재 단계

작업계획 문서 저장 완료 후 대상 파일 원본 백업을 먼저 생성하고, 백업 경로와 검증 결과를 보고한 뒤 수정을 시작한다.
