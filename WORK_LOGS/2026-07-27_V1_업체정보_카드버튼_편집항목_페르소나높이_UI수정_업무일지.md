## 1. 작업 목적

V1 업체 정보 화면에서 불필요한 상단 설명 카드를 제거하고, 업체 추가·수정 동선을 카드 내부에 모은다. 편집 화면의 항목 명칭을 사용자 마이페이지와 일치시키고 업체 페르소나 표시 높이를 확대한다.

## 2. 사용자 요청

1. `신규 업체 등록`을 `추가 업체 등록`으로 변경
2. 추가 업체 버튼을 업체 목록 카드 우측에 배치
3. `업체 관리`, `마이페이지 업체 자산`, 안내 문구가 있는 상단 카드 전체 숨김
4. 업체별 `수정` 버튼을 전화번호 뒤 최우측으로 이동하고 크게 강조
5. 우측 업체 편집 화면을 사용자 마이페이지와 비교하고 누락 항목 보강
6. 업체 페르소나 영역을 기존 높이의 약 1.5배로 확대

## 6. 적용 내용

### 상단 카드

- React DOM은 삭제하지 않고 `display: none !important`로 숨김
- 숨김 대상은 `마이페이지 업체 자산` 제목을 가진 해당 섹션으로 한정

### 추가 업체 버튼

- 원래 `신규 업체 등록` 버튼의 React 이벤트를 그대로 사용
- 업체 목록 카드 상단 우측에 `추가 업체 등록` 버튼 생성
- 새 버튼 클릭 시 원래 React 버튼을 호출
- 저장 함수와 API는 변경하지 않음

### 수정 버튼

- 각 업체 카드의 기존 `수정` 버튼을 전화번호 뒤 마지막 요소로 이동
- `margin-left: auto`로 카드 최우측 배치
- 데스크톱 최소 너비 86px, 모바일 92px
- 높이 38px, 시안색 테두리·배경·그림자로 시인성 강화

### 편집 화면 명칭 통일

- `웹사이트` → `홈페이지/SNS 선택`
- `콘텐츠 스타일` → `기본 작성 채널`
- `기본 말투` → `기본 감성 톤`
- `키워드` → `핵심 키워드`
- `업체 페르소나 내용` → `페르소나 상세 설명`
- 홈페이지/SNS와 페르소나 입력 안내 문구를 마이페이지 기준으로 보강

### 페르소나 높이

- 기존 데스크톱 약 176px → 264px
- 기존 모바일 약 160px → 240px
- 모두 기존 대비 약 1.5배
