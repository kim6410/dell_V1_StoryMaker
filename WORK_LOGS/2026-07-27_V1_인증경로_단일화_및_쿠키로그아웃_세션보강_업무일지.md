## 6. 쿠키 기반 로그아웃 세션 종료 보강

수정 파일:

`storymaker-web/backend/app/api/auth.py`

기존 문제:

Authorization 헤더가 없는 쿠키 기반 로그아웃에서는 즉시 쿠키만 삭제하고 반환했습니다.

이 때문에 JWT 쿠키 안 `session_id`를 읽지 않아 `user_sessions.logout_at`, `last_seen_at`, `duration_seconds`가 갱신되지 않는 경로가 있었습니다.

변경 내용:

```python
token = credentials.credentials if credentials else request.cookies.get(AUTH_COOKIE_NAME)
if not token:
    _clear_auth_cookie(response, request)
    return CommonResponse(ok=True, data=None, message="이미 로그아웃된 상태입니다.")

payload = verify_access_token(token)
```

효과:

- Authorization 헤더가 있으면 기존 Bearer 토큰 사용
- 헤더가 없으면 `storymaker_token` 쿠키 사용
- 유효한 쿠키 JWT의 `session_id`로 기존 세션 종료 로직 실행

검증:

- `python3 -m py_compile auth.py`: 통과
- 수정 후 SHA-256:
  - `8efdebc094b6659bef7a1e922794853fb08ae35e8f330155c18720fc3b71fa88`
