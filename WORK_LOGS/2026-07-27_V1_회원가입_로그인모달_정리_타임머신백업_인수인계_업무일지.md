## 2. 확인된 핵심 원인

1. V1 React 인증은 `/v1-api/auth/*`를 사용하지만, V1 페이지가 로드하는 공용 `app_auth.js`는 `/api/auth/*`를 사용한다.
2. V1 `index.html`이 `/static/v1/...`가 아닌 공용 `/static/...` 인증 자산을 로드한다.
3. `auth_modal_unified.js`와 `app_auth.js`가 동일 전역 함수와 모달 DOM의 소유권을 중복으로 가진다.
4. WordPress 가입은 사용자를 먼저 만든 후 메일을 발송하므로, 메일 실패나 미수신이어도 WordPress 사용자 행이 남을 수 있다.
5. Hostinger 인증 플러그인은 `email_verified=true`를 고정 반환하며 실제 인증 완료 상태를 로그인 차단 조건으로 사용하지 않는다.
6. V1 로컬 사용자 DB는 WordPress 로그인 후 생성되는 그림자 프로필 성격이며 이메일 인증 상태 컬럼이 없다.
7. WordPress 사용자 목록 동기화 호출은 HTTP 401 상태로 확인되어 기존 사용자 정합성 대조가 막혀 있다.

### 단계 0: 현재 상태 재확인

### 단계 1: 인증 경로 지도 작성

로그인, 로그아웃, 회원가입, 비밀번호 찾기, 회원관리 각각에 대해 다음을 표로 확정한다.

- 화면 소유 파일
- 호출 API
- 처리 서버
- 사용 DB
- 쿠키 이름·Domain·Path·SameSite
- 사용자 ID 연결 키

이 단계는 읽기 전용으로 수행한다.

### 단계 2: V1 인증 정적 자산 경로 단일화

- V1 전용 인증 자산을 `/static/v1/auth/` 계열로 배치
- V1 `index.html`에서 공용 `/static/auth_modal_unified.js`, `/static/app_auth.js` 로드 제거
- 모든 V1 인증 API를 `/v1-api/auth/*`로 고정
- 외부 기본 upstream의 인증 파일은 수정하지 않음
- 기존 로그인 동작은 그대로 유지

이 단계에서는 회원가입 프로토콜과 WordPress DB를 변경하지 않는다.

### 단계 3: 단일 모달 컨트롤러

- DOM·상태·포커스 소유자를 한 파일로 통합
- 전역 진입점 하나만 유지
  - 예: `window.StoryMakerAuth.open('login')`
- 중복 `showAuthModal`, `ensureStoryMakerLoginModal` 제거 또는 내부화
- 로그인·회원가입·비밀번호 찾기·인증 대기 상태를 명시적 상태 머신으로 관리
- 모바일 `100dvh`, safe-area, 포커스 트랩, 포커스 복귀, `aria-live` 적용

### 단계 4: WordPress 사용자 동기화 401 복구

- 자격 증명 값은 출력하지 않음
- WordPress ID 기준으로 V1 사용자와 대조
- 다음 범주만 읽기 전용 집계
  - WordPress + V1 정상 연결
  - WordPress에만 존재
  - V1에만 존재
- 이 단계에서는 사용자 삭제·병합 금지

### 단계 5: pending registration 추가

- 이메일 인증 전 WordPress 사용자 생성 금지
- 가입 요청 단계에서는 사용자명·이메일만 받기
- 토큰 원문이 아닌 해시 저장
- 만료·일회성·재전송 제한·rate limit 적용
- 인증 성공 시에만 WordPress 사용자 생성
- 비밀번호는 인증 후 설정

### 단계 6: 신규 가입에만 인증 강제

기능 플래그 권장:

- `V1_AUTH_MODAL_V2`
- `V1_PENDING_REGISTRATION`
- `V1_REQUIRE_VERIFIED_EMAIL`

초기 운영 원칙:

- 기존 사용자 로그인 유지
- 신규 가입만 pending 방식 적용
- 관리자 계정 보호
- 문제 발생 시 신규 가입만 차단 가능

### 단계 7: 관리자 회원관리 정리

회원관리 모달에 상태를 명확히 표시한다.

- WordPress 연결됨
- V1 연결됨
- 양쪽 정상
- WordPress만 존재
- V1만 존재
- 가입 대기
- 메일 실패
- 재인증 필요
- 로그인 제한

삭제보다 비활성화·재인증·보존을 먼저 적용한다.
