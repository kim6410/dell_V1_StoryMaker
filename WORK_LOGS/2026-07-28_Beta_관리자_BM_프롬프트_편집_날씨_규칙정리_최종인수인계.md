## 4. 완료된 기능

### 4.1 관리자 B 버튼

우측 상단 관리자 전용 버튼:

`B — 프롬프트 편집`

기능:

- 공통 프롬프트 전체 조회
- 프롬프트 편집
- 저장
- 필수 변수 검증
- 저장본이 없거나 오류 발생 시 코드 기본 프롬프트 폴백

관리자 저장 프롬프트 위치:

`/home/bourne/StoryMaker_1/StoryMaker_beta/data/admin_prompt_template.md`

필수 변수:

- `{{company}}`
- `{{region}}`
- `{{service}}`
- `{{phone}}`
- `{{source_text}}`
- `{{weather_block}}`

### 4.2 관리자 M 버튼

우측 상단 관리자 전용 버튼:

`M — 전송 프롬프트`

기능:

- 현재 작업의 실제 최종 전송 프롬프트 표시
- 읽기 전용
- 복사 가능
- 수정 및 저장 기능 없음

M은 현재 작업 큐에 저장된 실제 `prompt`를 읽어 표시하는 구조임.

### 4.3 관리자 권한 보호

- 일반 사용자에게 B·M 버튼 숨김
- 서버 API에서 관리자 권한 재검사
- 단순 프런트 숨김에 의존하지 않음

## 6. 최종 확정된 프롬프트 규칙

### 6.1 플레이스·구글 전화번호

최종 기준:

- `NAVER_PLACE_NEWS`에는 전화번호를 넣지 않음
- `GOOGLE_BUSINESS_POST`에는 전화번호를 넣지 않음
- 자연스러운 문의 또는 방문 유도 문장으로 마무리

관리자 저장 프롬프트와 코드 기본 프롬프트 모두 같은 기준으로 수정 완료.

### 6.2 굵은 표시

최종 기준:

- 핵심 내용에 `**굵은 표시**`를 10회 이상 자연스럽게 적용
- 무작위 강조 금지
- 지역 + 서비스, 상품·메뉴 특징, 핵심 작업, 문제 증상, 전문 판단, 해결 방법, 이용 가치, 실제 결과를 우선 강조

관리자 저장 프롬프트와 코드 기본 프롬프트 모두 `10회 이상`으로 통일 완료.

## 9. 현재 남은 문제

### 9.1 프롬프트 내부 중복

현재 관리자 프롬프트에는 다음 구간이 중복됨:

- 반드시 생성할 결과물
- 최상위 출력 규칙
- 13개 BLOCK 목록
- 모바일 가독성 규칙
- 공통 작성 규칙
- 전화번호 규칙
- 블로그 규칙

기능상 생성은 가능하지만 프롬프트가 불필요하게 길고, 향후 규칙 변경 시 앞뒤 문구가 다시 충돌할 위험이 있음.

### 9.2 업종 범용성

현재 구조는 변수 기반이므로 특정 업체·지역에 고정되지는 않음.

다만 일부 전개 규칙이 `문제 → 원인 → 해결` 중심이라 집수리·설비·청소 업종에 조금 더 최적화되어 있음.

다음 단계에서는 음식점·카페·미용·안경·교육·물류·전문 서비스에도 자연스럽게 적용되도록 업종별 전개 분기 규칙을 검토할 수 있음.

이번 작업에서는 사용자가 확정한 전화번호와 굵은 표시 규칙만 수정했고, 업종 전개 구조는 변경하지 않음.

### 9.3 날씨 지역 매핑

현재 날씨 좌표 매핑은 광역 단위 중심임.

남양주, 양주, 하남, 경주 등 세부 시·군·구가 광역명 없이 입력되면 대표 좌표가 정확하지 않을 가능성이 있음.

향후 전국 시·군·구 또는 기존 StoryMaker 지역 데이터와 연결하는 개선 필요.
