# StoryMaker Beta 관리자 B·M 프롬프트 기능 1차 구현

작성일: 2026-07-28

## 작업 목표

관리자 화면 우측 상단에 다음 버튼을 추가한다.

- B: 프롬프트 편집
- M: 전송 프롬프트

B는 공통 프롬프트 템플릿을 수정 저장한다.
M은 현재 작업에 실제 저장된 전송 프롬프트를 읽기 전용으로 확인하고 복사한다.

## 사용자 확인 항목

관리자 로그인 상태에서 딸깍 Beta 화면을 새로고침한다.

1. 우측 상단에 B·M 버튼이 표시되는지 확인
2. B 클릭 시 `프롬프트 편집` 팝업이 열리는지 확인
3. 저장 후 다음 ③ 프롬프트 생성부터 수정본이 적용되는지 확인
4. M 클릭 시 현재 작업의 `전송 프롬프트`가 읽기 전용으로 표시되는지 확인
5. 일반 사용자에게 B·M 버튼이 표시되지 않는지 확인
