## 다음 작업 최우선 목표

### Beta MP4 메타데이터 영구 기록

목적:

- 무료 사용자 월 20회 제한
- 유료 사용자 사용 횟수 통계
- 관리자 MP4 정상 생성 여부 판단
- 파일 삭제 후에도 생성 성공 기록 유지

중요 원칙:

- 단순 작업 생성 수가 아니라 `Beta MP4 정상 생성 완료 건수`를 사용량으로 계산한다.
- MP4 파일이 나중에 삭제돼도 메타데이터는 Beta DB에 영구 유지한다.
- V1 DB와 V1 제작 엔진에는 추가하지 않는다.
- Beta 서버 MP4와 Beta 브라우저 MP4 저장 경로를 모두 조사한 뒤 공통 기록 함수를 적용한다.
- 기존 제작 흐름을 깨지 않는 최소 변경으로 진행한다.

권장 최소 필드:

- `mp4_status`
- `mp4_size_bytes`
- `mp4_duration_seconds`
- `mp4_width`
- `mp4_height`
- `mp4_created_at`
- `mp4_verified`

가능하면 추가:

- `mp4_codec`
- `mp4_validation_result`
- `mp4_source` (`browser` 또는 `server_fallback`)

권장 성공 기준:

- 실제 MP4 파일 존재
- 파일 크기 0 초과
- ffprobe 또는 브라우저 메타데이터로 재생 길이 확인
- width/height 확인
- 검증 성공 시 `mp4_status='completed'`, `mp4_verified=1`
- 실패 또는 미생성은 사용량에 포함하지 않음

삭제 전 동작:

1. MP4 파일 메타데이터 확보
2. Beta DB 저장
3. 파일 삭제
4. `media_deleted_at`, `media_deleted_bytes`, `media_delete_reason` 갱신
5. MP4 메타데이터는 절대 지우지 않음

삭제된 작업 상세 팝업에 표시할 최소 정보:

- MP4 정상 생성 완료 / 생성 실패 / 기록 없음
- 파일 크기
- 재생 시간
- 해상도
- 생성 완료 시각
- 삭제 전 검증 여부

예시:

`MP4 정상 생성 완료 · 12.8MB · 54초 · 1080×1920 · 삭제 전 검증 완료`
