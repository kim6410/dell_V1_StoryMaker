## 반영 내용

### 상단

- 긴 제목은 PC에서 최대 2줄로 제한
- 모바일은 최대 3줄
- `BETA ARCHIVE RECORD` 배지 표시
- `작업 기록 보존 중` 안내 배너 표시
- 사용량·추이·과금 분석용 DB가 유지된다는 설명 표시

### SNS 콘텐츠

- 실제 저장된 채널 원고가 있으면 채널 탭·본문·복사 바 유지
- 채널 원고가 없으면 빈 검은 영역과 0자 복사 버튼을 제거
- 대신 `저장된 채널 원고가 없습니다` 안내 표시

### 미디어

삭제 작업에서는 기존의 큰 빈 카드 4개를 표시하지 않는다.

대신 단일 상태 요약 카드에 다음을 표시한다.

- 저장 파일 정리 완료
- 삭제 일시
- 확보 용량
- 삭제 사유
- 이미지 삭제됨
- MP3 삭제됨
- SRT 삭제됨
- 썸네일 삭제됨
- MP4 삭제됨
- 미리보기와 ZIP 다운로드 사용 불가 안내

### 정상 작업
