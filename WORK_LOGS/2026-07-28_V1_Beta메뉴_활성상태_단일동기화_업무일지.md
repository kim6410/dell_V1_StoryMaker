## 증상

- `업체 정보` 메뉴를 선택한 뒤 `딸깍 제작 Beta` 또는 `보관함 Beta`로 이동하면 기존 `업체 정보` 버튼의 활성 스타일이 남아 있었음.
- 현재 화면과 좌측 메뉴 활성 표시가 일치하지 않아 두 메뉴가 동시에 선택된 것처럼 보였음.

## 원인

- Beta 화면은 기존 React 콘텐츠를 숨기고 iframe 패널을 삽입하는 독립 메뉴 브리지 방식임.
- Beta 버튼에는 `data-active`만 설정했지만, 기존 React 메뉴에 남은 활성 클래스와 `aria-current` 상태는 제거하지 않았음.
- React DOM 변경 뒤 기존 메뉴 활성 스타일이 다시 생길 수 있었음.

## 수정 내용

1. `ACTIVE_MENU_CLASSES` 공통 목록 추가.
2. `syncBetaMenuSelection(activeKey)` 추가.
3. Beta 화면 진입 시 좌측 모든 메뉴 버튼에서 기존 활성 클래스와 `aria-current`, `data-active` 제거.
4. 현재 Beta 메뉴 한 개에만 활성 클래스와 `aria-current="page"` 적용.
5. MutationObserver 재실행 시 Beta iframe이 열려 있으면 현재 URL의 `page` 값을 기준으로 활성 상태 재동기화.
6. 일반 메뉴 클릭 시 기존 Beta 활성 상태는 해제하고 React 메뉴의 정상 선택 처리는 유지.
7. 정적 캐시 버전을 `20260728-menu-active-sync-1`로 갱신.
