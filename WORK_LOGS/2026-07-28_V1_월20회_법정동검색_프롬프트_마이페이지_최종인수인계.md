### 2.6 마이페이지 버튼 UX

- 마이페이지 상단 우측에 `저장 / 수정`, `로그아웃` 버튼을 추가했다.
- 상단 저장 버튼은 기존 하단 React 저장 버튼을 그대로 호출한다.
- 저장 API가 성공한 경우에만 마이페이지 팝업을 자동으로 닫는다.
- 상단과 하단 로그아웃 버튼은 작은 Yes/No 확인 팝업을 거친다.
- 팝업이 열리면 `예`가 기본 포커스다.
- 키보드 Enter 1회는 재확인 문구를 표시하고, Enter 2회에서 실제 로그아웃한다.
- 마우스로 `예`를 누르면 즉시 로그아웃한다.
- 실제 로그아웃은 `window.handleLogout()`을 우선 호출해 서버 세션, HttpOnly 쿠키, 로컬 토큰을 정리한다.
