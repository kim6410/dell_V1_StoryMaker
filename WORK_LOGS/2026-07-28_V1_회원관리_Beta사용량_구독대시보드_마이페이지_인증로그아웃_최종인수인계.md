## 4. 마이페이지 버튼과 로그아웃 개선

수정 파일:

`storymaker-web/backend/app/static/v1/mypage-action-enhancer.js`

`storymaker-web/backend/app/static/v1/index.html`

상단과 하단에 동일한 버튼 세트를 배치했다.

- 저장 / 수정
- 로그아웃
- 닫기

기존 React 하단 버튼은 내부 이벤트 연결 보호를 위해 삭제하지 않고 화면에서 숨긴다.

닫기 버튼은 저장 여부를 묻지 않고 즉시 닫힌다.

로그아웃 확인 후에는 마이페이지 닫기 로직을 먼저 실행하지 않는다.

기존에는 마이페이지를 닫는 과정에서 React가 `저장하시겠습니까?`를 표시했다.

현재 로그아웃 순서:

1. 로그아웃 확인
2. 서버 세션 종료
3. 로컬 인증정보 정리
4. V1 기본 대시보드 이동

관리자와 일반 사용자 모두 로그아웃 시 저장 질문이 나타나지 않는다.

## 5. 로그인·인증 흐름 개선

수정 파일:

`storymaker-web/backend/app/static/v1/auth/auth_modal_unified.js`

`storymaker-web/backend/app/static/v1/auth/auth_modal_unified.css`

`storymaker-web/backend/app/static/v1/auth/app_auth.js`

`storymaker-web/backend/app/static/v1/index.html`

### 로그인 성공 후 관리자 메뉴

로그인 모달은 React 외부 스크립트에서 인증 상태를 갱신하지만, React 좌측 메뉴는 인증 상태를 즉시 다시 읽지 않아 관리자 로그인 직후 메뉴가 보이지 않았다.

로그인 성공 후 인증 변경 이벤트를 전달하고 V1 화면을 깨끗한 주소로 한 번 재진입하도록 보강했다.

이제 별도의 `Ctrl+R` 없이 관리자 좌측 메뉴가 표시된다.

### 정의되지 않은 함수 오류

로그인 성공 뒤 다음 오류가 표시되던 문제를 방어했다.

- `log is not defined`
- `showToast is not defined`

인증 전용 안전 로그·알림 함수를 사용하여 후처리 오류가 로그인 실패처럼 보이지 않게 했다.

### 불필요한 로그인 모달 재노출

주소에 다음 파라미터가 남아 있으면 로그인 모달이 페이지 로드 때마다 자동으로 다시 열리는 문제가 있었다.

- `action=login`
- `action=register`
- `action=join`
- `action=password`
- `action=lostpassword`

인증 액션을 한 번 처리한 즉시 URL에서 해당 파라미터를 제거한다.

로그인 성공 후 자동 재진입도 깨끗한 `/v1/` 주소를 사용한다.

`auth_modal_unified.js`와 `app_auth.js`가 URL 액션을 중복 처리하지 않도록 방어했다.
