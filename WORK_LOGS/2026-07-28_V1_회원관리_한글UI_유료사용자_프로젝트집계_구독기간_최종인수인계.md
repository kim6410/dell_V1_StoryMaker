### 2.6 요금제 관리

관리자 상세 화면에서 표시하는 요금제를 Free와 Starter로 단순화했다.

- Free: 0원
- Starter: 월 4,500원

무료 회원:

- 현재 이용 가능 횟수 표시
- 누적 사용량 표시
- `무료 20회 추가 지급` 버튼 표시
- 관리자가 필요할 때마다 20회씩 추가 지급 가능

Starter 회원:

- 유료 회원·Starter 상태 표시
- 월 4,500원 표시
- 첫 1개월 무제한 안내
- 사용량만 집계 중임을 표시
- 무료 추가 지급 및 유료 추가충전 버튼 숨김

추가 API:

`POST /v1-api/admin/members/{user_id}/billing/free-bonus-credit`

무료 회원에게만 20회를 지급하며 유료 회원 호출은 서버에서 차단한다.

### 2.7 구독 시작일·종료일

관리자가 Starter로 변경한 시점에 다음 값을 저장한다.

- `current_period_started_at`: 적용 시각
- `current_period_ends_at`: 적용일 기준 1개월 뒤
- `next_billing_at`: 종료일과 동일
- `subscription_status`: active

월말 날짜는 다음 달 실제 마지막 날짜에 맞춘다.
예: 1월 31일 → 2월 28일 또는 윤년 2월 29일.

Free로 변경하면 구독기간과 다음 결제일은 비운다.

Starter 상세 화면에는 구독 시작일과 구독 종료일 카드를 표시한다.

### 2.8 회원 삭제 정책

- 목록의 `선택 회원 삭제` 유지
- 상세 화면에 `회원 삭제` 버튼 추가
- StoryMaker 로컬 회원 삭제 API 사용
- WordPress 회원은 삭제하지 않음
- 관리자 본인과 마지막 활성 관리자 보호 로직 유지
- 삭제 확인창에 계정과 대표 업체명을 표시

WordPress에서 회원을 삭제해도 StoryMaker 로컬 회원은 자동 삭제되지 않는다. 운영자는 당분간 양쪽을 직접 관리한다.

### 2.9 화면 멈춤 원인과 수정

원인:

- 한글 UI 보강 스크립트의 `MutationObserver`가 자신이 변경한 DOM을 다시 감지했다.
- 표 재구성과 회원별 API 조회가 반복되어 브라우저가 느려지거나 멈출 수 있었다.

수정:

- `characterData` 감시 제거
- 80ms 디바운스 적용
- 이미 변환된 회원 행은 다시 만들지 않는 가드 적용
- 회원 상세 번역은 목록 재구성 완료 후 실행
- 회원 데이터 조회 Promise 캐시 적용
