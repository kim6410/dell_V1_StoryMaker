### 5. 썸네일 이미지 선택 카드 개선

- 이전: `배경 이미지 변경`
- 현재: `이미지 선택`

- 이미지 선택 아이콘 추가
- 현재 선택 이미지를 카드 배경에 희미하게 표시

### 6. 배경 이미지 선택창 최상단 표시

썸네일 생성 화면에서 `이미지 선택`을 누르면 이미지 선택창이 화면 아래쪽이 아니라 썸네일 화면 최상단부터 보이도록 수정했다.

- 모달 정렬: `place-items:start center`
- 모달 내부 스크롤을 항상 0으로 초기화
- iframe의 상위 창까지 계산하여 썸네일 생성 화면 상단으로 이동
- 닫기 버튼 포커스는 `preventScroll:true`
