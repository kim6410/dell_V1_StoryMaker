# StoryMaker Dell V1·Beta 가입일 30일 AI 원고·MP4 차단 작업 준비 인수인계

작성일: 2026-07-29

## 작업 원칙

- 무료·유료 사용자 모두 `users.created_at`을 최초 기준일로 사용한다.
- 가입 시각부터 정확히 30일을 한 이용기간으로 계산한다.
- 무료 사용자는 현재 30일 이용기간의 검증 완료 MP4와 유효한 예약 슬롯이 20건 이상이면 차단한다.
- 유료 사용자는 유료 이용기간이 끝난 다음 시각부터 갱신 확인 전까지 차단한다.
- 차단 대상은 새 AI 원고 생성과 새 MP4 렌더링·MP4 업로드 두 단계뿐이다.
- 기존 콘텐츠 열람·복사·다운로드·보관함·업체 정보는 차단하지 않는다.
- 콘텐츠 자동 정리로 미디어가 삭제돼도 MP4 사용 이력은 유지한다.

## 현재 확인된 문제

- V1 대시보드는 가입일 기준 30일 집계를 사용하도록 보강됐다.
- Beta 실제 MP4 차단 함수는 `member_billing_profiles.current_period_started_at/current_period_ends_at`을 우선 사용해 대시보드와 기간 기준이 다르다.
- `obarksa` 사용자 ID 83 기준 가입 후 검증 완료 MP4는 30건, 현재 보관 중은 10건이다.
- 기존 Beta 차단 기간에서는 사용량이 11건으로 계산돼 화면은 0건 남음인데도 실제로 추가 생성이 가능한 불일치가 확인됐다.
