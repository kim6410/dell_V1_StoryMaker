## 이번 작업 완료 내용

### 1. 마이페이지 상단 버튼 간헐적 텍스트 표시 보강

`mypage-action-enhancer.js`에서 마이페이지 요소 탐색 성공 여부와 무관하게 버튼 스타일을 먼저 설치하도록 변경했습니다.

대상 버튼:

- 저장 / 수정
- 로그아웃
- 닫기

목표는 렌더링 타이밍이나 브라우저 캐시 차이로 버튼 CSS가 늦게 적용돼 글자만 붙어 보이는 간헐적 현상을 줄이는 것입니다.

### 2. 대시보드 연구실 카드 권한 분리

`v1-dashboard-inline-labs.js`에서 다음 카드는 관리자 인증이 확인된 경우에만 표시합니다.

- AI 연구실
- 네모트론 연구실

일반 사용자에게는 COMPANY 카드만 남깁니다.

`다음 작업 목록` 영역은 관리자와 일반 사용자 모두에서 제거합니다.

제거 대상:

- 다음 작업 목록
- 업체 DB
- 프로젝트
- 빈 카드

관리자 판정은 `/v1-api/auth/me` 응답을 기준으로 합니다.

### 3. COMPANY 카드 유지 및 업체 정보 연결

일반 사용자 화면에서 연구실 카드의 상위 컨테이너까지 숨겨 COMPANY 카드가 같이 사라지던 문제를 방지했습니다.

COMPANY 카드는 유지하며 클릭하면 사이드바의 `업체 정보` 화면을 엽니다.

### 4. 비로그인 사용자 전용 사용해보기 버튼

신규 파일:

`storymaker-web/backend/app/static/v1/v1-guest-try-login-card.js`

비로그인 사용자에게만 상단 `현재 화면 / 대시보드` 헤더 중앙에 다음 버튼을 표시합니다.

`스토리메이커 사용해보기`

버튼 클릭 시 기존 V1 로그인 모달을 엽니다.

인증 판정은 다음을 함께 사용합니다.

- 쿠키 인증
- `localStorage.storymaker_token`
- `Authorization: Bearer <token>`
- `/v1-api/auth/me`의 `payload.data.user`, `payload.user`, `payload.data`

일반 로그인 사용자와 관리자는 버튼을 표시하지 않습니다.

### 5. 대시보드 브랜드 문구 정리

기존:

`StoryMaker AI v1`

최종 표시:

`스토리메이커` + 작은 `자동` 캡슐 배지

상단 영문 `STORYMAKER`와 하단 `소상공인 콘텐츠 대시보드` 문구는 유지합니다.

브랜드 블록 클릭 시 초기 대시보드로 이동하는 기존 동작도 유지합니다.

### 6. 메뉴·브랜드 경로 인식 보강

브랜드 문구가 한글로 바뀌어도 V1·V2 메뉴 경로 브리지에서 브랜드 블록을 정상 인식하도록 보강했습니다.

관련 파일:

- `v1-brand-home-link.js`
- `v1-menu-route-bridge.js`
- `v2-menu-route-bridge.js`

### 7. 업체 정보·관리자 요청 UI 유지

이번 커밋에는 이전부터 작업 트리에 남아 있던 다음 V1 UI 변경도 함께 포함합니다.

- `v1-company-info-ui-tune.js`
- `v1-admin-request-alert.js`

두 파일은 현재 `index.html`에서 실제 로딩되는 V1 보조 스크립트이며, 이번 V1 UI 정리 범위에 포함해 함께 추적합니다.
