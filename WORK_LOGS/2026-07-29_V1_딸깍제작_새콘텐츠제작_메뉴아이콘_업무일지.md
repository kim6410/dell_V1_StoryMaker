## 변경 내용

### 메뉴명 변경

DOM의 텍스트 노드 중 정확히 `딸깍 제작`인 항목만 찾아 `새 콘텐츠 제작`으로 바꾸는 `renameCreationMenu()`를 추가했다.

부분 문자열이나 안내 문구는 변경하지 않으므로 기존 기능 설명과 경고 문구에는 영향을 주지 않는다.

### 메뉴 아이콘 연결

`install()` 실행 순서를 아래와 같이 정리했다.

1. 브랜드 연결
2. 기존 하드코딩 버튼 연결
3. 제작 메뉴명 변경
4. 중복·기존 아이콘 제거
5. 메뉴별 SVG 아이콘 재설치

MutationObserver가 기존 `install()`을 계속 호출하므로 React 화면이 다시 렌더링돼도 메뉴명과 아이콘이 복원된다.
