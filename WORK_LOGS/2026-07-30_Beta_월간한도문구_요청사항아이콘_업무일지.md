# Beta 월간 한도 문구·요청사항 아이콘 업무일지

작성일: 2026-07-30

## 작업 목표

무료 한도 초과 안내 모달의 제목을 사용자 친화적으로 변경하고, 본문 끝에 말풍선 아이콘을 추가해 기존 V1 요청사항 작성 모달을 바로 열 수 있도록 연결한다.

## 변경 내용

- 제목 변경
  - 기존: `무료 제작 한도를 모두 사용했습니다`
  - 변경: `월간 무료 한도를 모두 사용하셨어요.`
- 무료회원 본문 끝에 말풍선 아이콘 버튼 추가
- 아이콘 접근성 속성 추가
  - `aria-label="요청사항 작성"`
  - `title="요청사항 작성"`
- 아이콘 클릭 시 Beta iframe에서 부모 V1 화면으로 `storymaker:open-feature-request` 메시지 전달
- V1 전용 브리지 스크립트 추가
  - 기존 `window.StoryMakerV1FeatureRequests.newRequest()` 호출
  - 요청 제목과 내용을 기본 입력한 상태로 기존 요청사항 모달 표시
- 유료기간 만료 안내에는 요청사항 아이콘을 표시하지 않음
- 기존 유료회원 가입, 확인, 차단 정책은 변경하지 않음
