# StoryMaker Beta 인라인 가입 링크·영상 만들기 사전 차단 업무일지

작성일: 2026-07-30

## 문제

- AI 프롬프트 생성 한도 초과 메시지가 `window.alert`가 아니라 `#beta-status` 인라인 영역에 출력되어 기존 안내 모달이 열리지 않았습니다.
- 브라우저 MP4 렌더러가 서버 저장 단계보다 먼저 실행되어, 한도 초과 사용자도 영상이 로컬에서 만들어질 수 있었습니다.

## 수정

- `beta-access-limit-modal.js`에서 `#beta-status`, `#sf-status`의 한도 차단 문구를 감지합니다.
- 인라인 상태 영역에 차단 이유와 `유료회원 가입` 링크를 직접 표시합니다.
- 가입 링크는 `https://www.latpeed.com/`를 새 창으로 엽니다.
- 인라인 안내와 함께 기존 한도 안내 모달도 표시합니다.
- `#sf-make` 클릭을 캡처 단계에서 가로채 `/beta-api/jobs/usage-summary`를 먼저 조회합니다.
- `access_allowed=false`이면 브라우저 렌더러 시작 전에 중단합니다.
- 허용 사용자만 기존 영상 만들기 클릭 핸들러를 실행합니다.
