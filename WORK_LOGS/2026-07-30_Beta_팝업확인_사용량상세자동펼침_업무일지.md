# Beta 한도 팝업 확인 버튼 사용량 상세 자동 펼침 업무일지

작성일: 2026-07-30

## 증상

한도 초과 팝업에서 `확인`을 누르면 V1 대시보드 메인 상단으로만 이동하고, 사용자가 기대한 `콘텐츠 제작 현황` 카드와 사용량 상세 위치로 이동하지 않았습니다.

## 원인

1. Beta 제작 화면은 V1 내부 iframe으로 실행됩니다.
2. iframe이 부모 V1에 대시보드 이동 메시지를 보낸 뒤 자체 폴백 URL 이동이 다시 실행되어 스크롤 위치가 초기화됐습니다.
3. 부모 화면도 대시보드 복원 후 단순 `window.scrollTo(0)`만 실행했습니다.
4. `콘텐츠 제작 현황` 카드는 비동기로 생성되므로 즉시 탐색하면 존재하지 않을 수 있습니다.

## 수정

### Beta 팝업

- 부모 V1 화면이 존재하면 `storymaker:navigate-dashboard` 메시지만 전송합니다.
- 부모 메시지 전송 성공 후 iframe 자체 `/v1/` 이동을 실행하지 않습니다.
- iframe 단독 실행일 때만 `/v1/#v1-dashboard-usage-panel`로 이동합니다.

### V1 부모 화면

- Beta iframe을 닫고 정상 대시보드 콘텐츠를 복원합니다.
- `콘텐츠 제작 현황` 루트 `#v1-dashboard-usage-panel`이 생성될 때까지 최대 4초간 탐색합니다.
- `이번달 사용량` 카드 `[data-v1d-usage]`를 자동 클릭합니다.
- 사용량 상세 `[data-v1d-detail]`을 자동으로 펼칩니다.
- 펼쳐진 상세 영역을 화면 중앙으로 스크롤하고 2.2초간 강조합니다.
