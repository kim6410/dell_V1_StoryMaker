# Beta 한도 팝업 확인 버튼 대시보드 이동 업무일지

작성일: 2026-07-30

## 증상

한도 차단 안내 팝업과 유료회원 가입 링크는 정상 동작했으나, 확인 버튼을 눌러도 V1 콘텐츠 제작 현황 대시보드로 이동하지 않았습니다.

## 원인

안내 팝업은 V1 내부의 Beta 제작 iframe에서 실행됩니다.

iframe 내부에서 window.top.location을 직접 변경하는 방식은 브라우저의 iframe 이동 제한에 따라 무시될 수 있었습니다.

## 수정

Beta iframe의 확인 버튼이 부모 V1 화면으로 storymaker:navigate-dashboard 메시지를 전달하도록 수정했습니다.

V1의 v1-beta-independent-menu.js가 같은 출처의 해당 메시지를 수신하면 다음을 수행합니다.

- Beta 독립 iframe 제거
- 숨겨졌던 기존 V1 대시보드 콘텐츠 복원
- Beta 메뉴 선택 상태 해제
- 주소를 /v1/로 변경
- 화면 상단으로 이동

직접 최상위 이동은 120ms 후 보조 폴백으로 유지했습니다.
