# Beta 한도 API 경로 및 회원별 제작 정책 수정 업무일지

작성일: 2026-07-30

## 원인

프런트 한도 확인 스크립트가 존재하지 않는 `/beta-api/jobs/usage-summary`를 호출했습니다.
FastAPI는 `usage-summary`를 작업 ID로 해석하여 `Beta 작업 DB 레코드를 찾을 수 없습니다.`를 반환했습니다.

또한 기존 정책은 유료회원도 30일 이용기간 종료 여부를 검사해 차단했습니다.
관리자 역할 헤더가 순간적으로 user로 전달되면 실제 관리자도 무료회원 한도에 걸릴 가능성이 있었습니다.

## 수정

- 한도 조회 API를 `/beta-api/usage-summary`로 수정
- 무료회원은 월 20회 유지
- 유료회원은 횟수와 기간 제한 없이 허용
- 관리자는 제한 없이 허용
- 관리자 여부를 요청 헤더와 V1 DB `users.role` 양쪽에서 확인
- 정적 파일 캐시 버전 갱신

## 수정 파일

- `StoryMaker_beta/app/beta_mp4_usage.py`
- `StoryMaker_beta/static/beta-access-limit-modal.js`
- `StoryMaker_beta/static/production.html`

## 검증

- Python 문법 PASS
- JavaScript 문법 PASS
- 관리자 정상 역할 무제한 PASS
- 관리자 역할 헤더가 user인 경우에도 DB 역할로 무제한 PASS
- 유료 starter 회원 무제한 PASS
- 무료회원 월 20회 제한 PASS
- 서명 인증 `/beta-api/usage-summary` HTTP 200
- Beta production HTTP 200
- V1 HTTP 200
- `storymaker-beta.service` active
