## 수정 내용

### 1. 실제 큐 요약 API 추가

수정 파일:

`StoryMaker_beta/app/beta_gemini_worker.py`

추가 API:

`GET /beta-api/gemini-worker/queue-summary`

V1에서는 인증 프록시를 통해 다음 주소로 호출한다.

`GET /v1/beta-api/gemini-worker/queue-summary`

API는 로그인 사용자의 서명된 사용자 ID를 사용한다.

다른 사용자의 업체명, 작업 제목, 이메일, job ID는 응답하지 않는다.

응답 항목:

- `processing_count`: 실제 활성 큐 중 `claimed`, `sent` 상태 수
- `my_position`: `queued_at` 순서로 정렬한 활성 큐에서 로그인 사용자의 첫 작업 순번
- `my_status`: `pending`, `claimed`, `sent`, `idle`
- `estimated_wait_seconds`: 내 앞 작업 수 × 최근 완료 작업 중앙 처리 시간
- `average_processing_seconds`: 최근 정상 완료 큐 최대 40개의 중앙값
- `active_count`: 실제 활성 큐 전체 수

최근 처리 시간은 3초 이상 300초 이하의 정상 완료 표본만 사용한다.

표본이 없을 때 기본값은 45초이며, 계산값은 10~180초 범위로 제한한다.

표현 기준:

- 내 작업 `claimed` 또는 `sent`: 순번 `처리 중`, 대기 시간 `처리 중`
- 대기 작업 있음: `N번째`, `약 N분` 또는 `약 1분 이내`
- 내 작업 없음: `대기 없음`, `바로 시작 가능`
