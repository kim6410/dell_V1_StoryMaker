## 실제 수정 파일

### 1. `storymaker-web/backend/app/static/v1/v1-beta-independent-menu.js`

- `betaProduction` 메뉴명을 `딸깍 제작`에서 `새 콘텐츠 제작`으로 변경
- `betaProduction` 메뉴 원본 데이터에 플러스 SVG 아이콘 추가
- `betaArchive` 메뉴 원본 데이터에 폴더 SVG 아이콘 추가
- 메뉴 렌더 구조를 `아이콘 + 메뉴명 + BETA 배지`로 명확히 분리
- 아이콘과 배지에 `shrink-0`, 메뉴명에 `truncate`를 적용해 줄바꿈과 겹침 방지
- 대시보드 Beta 제작 카드 문구도 `새 콘텐츠 제작`으로 통일

- Beta 독립 메뉴 원본이 만든 SVG를 후처리 코드가 삭제하지 않도록 변경

## 근본 해결 구조

이전 실패 방식은 MutationObserver 또는 텍스트 검색 후 아이콘을 삽입하는 후처리 방식이었다.

이번 수정은 메뉴 원본 객체가 아이콘을 보유하고 메뉴 버튼 생성 시 정확히 한 번 렌더링한다.

메뉴 DOM이 다시 생성되어도 새 버튼에는 원본 아이콘이 한 개만 포함되므로 누적 삽입이 발생하지 않는다.

## 타임머신 롤백 방법

가장 안전한 롤백은 이번 작업 완료 커밋을 Git revert하는 방식이다.

작업 전 상태를 직접 확인해야 할 경우 기준 태그는 다음과 같다.

```bash
git -C /home/bourne/StoryMaker_1 show v1-menu-before-icon-source-20260730-0006
```

긴급 복구 시에는 전체 reset을 사용하지 않고, 이번 작업 커밋만 다음처럼 되돌린다.

```bash
git -C /home/bourne/StoryMaker_1 revert --no-edit <이번_작업_커밋>
sudo -u bourne -H git -C /home/bourne/StoryMaker_1 push origin main
```

파일 단위 복구가 필요한 경우 위 자동 백업 파일을 기준으로 대상 파일만 복구한다.
