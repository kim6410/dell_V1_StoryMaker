# StoryMaker V1 실시간 대기열 중복 카드 제거 업무일지

작성일: 2026-07-30

## 작업 목표

V1 좌측 사이드바에서 기존 `작업 현황` 카드와 새 `실시간 대기열` 카드가 번갈아 또는 동시에 표시되는 현상을 제거한다.

새 실시간 대기열 카드 한 개만 유지하고, 문구 `예상 대기 시간`을 `대기시간`으로 변경한다.

## 원인

V1 React 화면이 사이드바를 재렌더링할 때 기존 모바일 원샷 `작업 현황` 카드가 다시 생성됐다.

기존 구현은 새 큐 데이터를 갱신할 때만 기존 카드를 재사용하거나 교체했기 때문에, React 재렌더링과 5초 갱신 사이에 두 카드가 함께 보일 수 있었다.

## 수정 파일

- `storymaker-web/backend/app/static/v1/v1-beta-independent-menu.js`

## 수정 내용

- `removeLegacyQueueCards()` 추가
- `QUEUE`와 `작업 현황`을 포함하는 기존 카드만 제거
- 새 카드 `#storymaker-live-queue-summary`는 제거 대상에서 제외
- MutationObserver가 React 재렌더링을 감지할 때 즉시 기존 카드를 제거
- 새 카드가 사라진 경우 실제 큐 API를 즉시 다시 조회해 복구
- `예상 대기 시간`을 `대기시간`으로 변경
