## 작업 목표

Beta 숏폼 제작 완료 후 표시되는 9:16 썸네일 8종의 왼쪽 상단 배지가 `현장 강조`, `문제 해결`, `숫자 강조`, `스토리형` 같은 고정 템플릿 문구만 표시하던 문제를 해결한다.

## 원인

`result.json`의 `content.source_blocks.BLOG_HASHTAGS`에는 블로그 해시태그가 정상 저장되고 있었다.

그러나 숏폼 context API가 해당 값을 응답하지 않았고, 숏폼 완료 이벤트와 썸네일 iframe 전달 데이터에도 해시태그 필드가 없었다.

썸네일 생성기는 배지를 그릴 수 있는 구조를 갖추고 있었지만 실제 `BLOG_HASHTAGS` 입력이 비어 있어 템플릿별 기본 문구로 폴백하고 있었다.

### 1. `StoryMaker_beta/app/beta_shortform.py`

숏폼 context API가 `content.source_blocks.BLOG_HASHTAGS`를 읽어 `blog_hashtags` 필드로 반환하도록 추가했다.

기존 카드뉴스, 인스타그램, 이미지, 음성 데이터 구조는 유지했다.

### 2. `StoryMaker_beta/static/beta-shortform-inline.js`

### 3. `StoryMaker_beta/static/production.html`

### 4. `storymaker-web/backend/app/static/v1/four-thumbnail/index.html`

해시태그가 없을 때만 기존 템플릿 고정 문구를 폴백으로 유지한다.

미리보기와 최종 PNG 내보내기가 같은 배지 값을 사용하도록 동일한 렌더 경로를 적용했다.
