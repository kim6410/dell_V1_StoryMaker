- 실패하거나 지연되는 경우 Dell Supertonic 서버가 즉시 이어받아 완주한다.

이 구조는 사용자 PC만 사용하는 최고속 세팅보다 서버 자원을 조금 사용할 수 있으나, 장시간 정지와 90초·236초 같은 비정상 지연을 막는다는 점에서 “동영상 생성 2등으로 빠른 세팅”으로 정의한다.

## 3. 기존 대성공 렌더 기준

기존의 가장 빠른 구조는 다음과 같다.

1. 사용자 PC 브라우저가 Canvas로 사진과 동영상 프레임을 합성한다.
2. Mediabunny·WebCodecs가 H.264 MP4를 생성한다.
3. 서버는 원본 미디어 전송과 최종 MP4 저장만 담당한다.
4. 정상 경로에서는 Dell 서버의 FFmpeg 전체 재인코딩을 사용하지 않는다.
5. 완성 MP4는 서버에 업로드되고 보관함과 썸네일 흐름으로 연결된다.

이 핵심 렌더 구조는 이번 작업에서도 변경하지 않았다.

## 5. 단계별 원인 분석

### 5.1 WebGPU 음성 추론 지연

느린 작업의 진단값에서는 다음이 확인됐다.

- WebGPU 어댑터 확인: 0ms
- ONNX 세션 생성: 0ms
- 음성 스타일 로딩: 약 83ms
- 실제 TTS 추론: 약 36초
- MP3 인코딩: 약 2.2초

즉 모델 다운로드나 GPU 어댑터 탐색이 느린 것이 아니라, 준비가 끝난 뒤의 실제 음성 추론이 간헐적으로 크게 느려졌다.

### 5.2 V1 자동 예열과 Beta 전용 Worker의 중복

V1 본체에는 `BROWSER AI`라는 WebGPU 음성 엔진 자동 예열 기능이 있었다.

동시에 Beta 제작 iframe의 `beta-browser-render.js`도 별도 Worker와 WebGPU 음성 모델을 준비했다.

결과적으로 같은 브라우저 탭 안에서 다음 두 음성 엔진이 동시에 존재할 수 있었다.

- V1 본체 자동 예열 Worker
- Beta 영상 제작 전용 Worker

이 구조는 GPU 메모리, WebGPU 실행 큐, 브라우저 스케줄링 자원을 서로 경쟁하게 만들 가능성이 높았다.

화면에 보이던 `90% · WebGPU 고성능 어댑터 확인 중` 문구는 실제 원인이 아니라 상태 표시가 오래 유지된 것이었다. 내부에서는 이미 어댑터와 세션 준비가 끝났고 TTS 추론이 진행 중이었다.

### 5.3 지나치게 긴 대기 제한

기존 브라우저 음성 생성 제한은 최대 120초였다.

브라우저 TTS가 비정상 상태에 들어가도 최대 2분 동안 기다릴 수 있어 전체 MP4 제작 시간이 크게 늘어날 수 있었다.

## 6. 최종 해결 방식

### 6.1 V1 자동 WebGPU 예열 중단

V1 본체가 페이지 진입 시 자동으로 WebGPU 음성 모델을 올리던 호출을 제거했다.

이제 자동 예열용 `BROWSER AI` 창은 표시되지 않으며 실제 영상 제작이 시작될 때 Beta 전용 Worker 하나만 음성 엔진을 준비한다.

효과:

- 중복 WebGPU 모델 로딩 방지
- GPU 메모리 경쟁 감소
- 음성 Worker 실행 경로 단일화
- 실제 제작 상태와 무관한 90% 고정 화면 제거

### 6.2 Beta 전용 Worker 단독 사용

숏폼 제작 중 음성 생성은 `beta-browser-render.js`의 Worker만 사용한다.

한 작업 안에서는 선택된 여성·남성 음성을 끝까지 유지한다.

랜덤 설정일 경우:

- 여성: F1~F5 중 선택
- 남성: M1~M5 중 선택
- 직전 랜덤 작업과 같은 음성의 연속 선택을 가급적 피함

사용자가 F4·M2처럼 직접 지정한 경우에는 해당 값을 그대로 사용한다.

### 6.3 WebGPU TTS 15초 제한

브라우저 음성 생성이 15초 안에 끝나지 않으면 느린 Worker를 종료한다.

동작 순서:

1. Beta 전용 WebGPU Worker에서 음성 생성 시작
2. 15초 이내 완료하면 브라우저 생성 결과 사용
3. 15초 초과 시 Worker 종료
4. Dell Supertonic 서버 TTS로 자동 전환
5. MP3·SRT·배경음악·MP4 제작을 계속 진행

기존 120초 대기보다 훨씬 빠르게 비정상 상태를 차단한다.

### 6.4 Dell 서버 폴백의 역할

서버 자원을 조금 사용하는 것은 오류가 아니라 의도된 안전장치다.

정상적인 브라우저 TTS가 15초 안에 끝나면 서버 부담은 거의 없다.

브라우저가 느려지거나 실패하면 Dell Supertonic이 음성 생성을 대신 수행하므로 서버 CPU 또는 GPU 사용량이 잠시 증가할 수 있다.

이 세팅은 다음 우선순위를 가진다.

- 1순위: 전체 제작 완주
- 2순위: 비정상 장기 대기 방지
- 3순위: 사용자 PC 우선 사용
- 4순위: 필요한 경우 서버 자원 허용
