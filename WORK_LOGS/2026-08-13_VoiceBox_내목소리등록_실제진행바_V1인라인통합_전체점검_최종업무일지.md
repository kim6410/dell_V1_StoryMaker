## 내 목소리 등록
Studio 상단 Voice Profile 옆에 `+ 내 목소리 등록` 버튼을 추가했다.

입력 항목:
- 프로필 이름
- WAV/MP3/M4A/FLAC/OGG/WebM/Opus 음성 샘플
- 샘플에서 실제로 읽은 문장
- 복제 엔진(Qwen3-TTS 우선, Chatterbox, LuxTTS)

백엔드 신규 경로:
`POST /v1-api/voicebox/profiles/clone`

V1 Backend가 관리자 인증을 확인한 뒤 VoiceBox `/profiles`와 `/profiles/{profile_id}/samples`를 순차 호출한다.
업로드 실패 시 생성된 빈 프로필을 정리하도록 cleanup을 포함했다.
파일 최대 크기는 50MB다.

## 음성 생성 Progress UI/UX
기존 `/generate/stream` 단일 장기 요청 방식 대신 Studio는 비동기 generation workflow를 사용한다.

신규 경로:
- `POST /v1-api/voicebox/generate/start`
- `GET /v1-api/voicebox/generate/{generation_id}/status`
- `GET /v1-api/voicebox/generate/{generation_id}/audio`

실제 상태 흐름:
- loading_model
- generating
- completed / failed

UI 단계:
- 모델 준비
- 음성 생성
- 오디오 수신
- 완료

VoiceBox가 내부 생성 퍼센트를 제공하지 않는 구간은 가짜 숫자를 만들지 않는다.
해당 구간은 indeterminate animation + 실제 경과시간을 보여준다.
완료된 WAV가 브라우저로 전송되는 구간은 Response body stream의 실제 수신 byte와 content-length로 실제 %를 표시한다.

실측 cold generation 검증:
- 0.0초: loading_model
- 10.4초: generating
- 29.8초: completed
- 생성 WAV: 5.28초 / 253,484 bytes

## GTX1060 VRAM 보호
Qwen CustomVoice 0.6B와 Qwen Base 0.6B를 동시에 GPU에 올리면 GTX1060 6GB VRAM을 거의 전부 사용한다.
따라서 V1 Adapter에 `_free_gpu_for_engine()`을 추가했다.

원칙:
- Sohee/qwen_custom_voice 사용 전 qwen base 계열 unload
- cloned qwen 사용 전 qwen custom voice 계열 unload
- 파일은 삭제하지 않고 GPU 메모리만 반환
- 다시 사용할 때 VoiceBox가 디스크 캐시에서 자동 load

다운로드 완료 모델:
- `qwen-custom-voice-0.6B`: 약 2382.64MB
- `qwen-tts-0.6B`: 약 2399.54MB
- VoiceBox runtime model cache 총량 약 4.7GB

## V1 대시보드 인라인 통합
기존 `v1-dashboard-inline-labs.js`가 AI 연구실과 네모트론을 대시보드 내부 iframe으로 전환하는 공통 시스템을 이미 제공한다.
VoiceBox를 별도 새 페이지 방식으로 유지하지 않고 이 공통 시스템의 세 번째 앱으로 등록했다.

- URL: `/static/v1/voicebox-studio.html?from=v1-admin&inline_lab_frame=1`

공통 인라인 툴바:
- AI 연구실
- 네모트론 연구실
- VoiceBox
- 대시보드로 돌아가기

기존 `v1-admin-voicebox-entry.js` 버튼 클릭 동작:
기존: `window.location.href = voicebox-studio.html`

따라서 주소창은 V1 `/v1/`을 유지하고, 현재 대시보드 콘텐츠 영역 안에서 VoiceBox iframe이 열린다.
VoiceBox iframe 내부의 중복 `V1 대시보드` 버튼은 숨긴다.

## 네트워크 재확인
VoiceBox listen: `0.0.0.0:17493`
UFW:
`17493/tcp ALLOW 172.27.0.0/16 # StoryMaker V1 VoiceBox from V1 docker network`

UFW 기본 inbound deny 상태에서 V1 Docker 내부망만 허용한다.
V1 container -> `http://172.27.0.1:17493/health` 실제 HTTP 200 확인.
따라서 현재 17493이 사내 LAN/외부 전체에 직접 공개된 상태는 아니다.

`STORYMAKER_VOICEBOX_URL` 환경변수는 현재 컨테이너에 별도 지정되지 않았으나 `voicebox.py` 기본값이 `http://172.27.0.1:17493`이고 실제 연결 검증을 통과했다.
향후 Docker network 변경 가능성을 고려하면 compose environment에 명시하는 개선은 별도 작업으로 가능하다.

## 추가 모델에 대한 판단
현재 StoryMaker VoiceBox의 핵심 목적은 TTS와 voice cloning이다.
Whisper STT, Chatterbox Turbo, Qwen 1.7B는 현재 기능 완료를 위해 필수 모델이 아니다.
GTX1060 6GB에서는 불필요한 모델 사전 로딩이 오히려 VRAM/디스크 부담을 키운다.
따라서 현재는 Qwen 0.6B 두 모델만 운영 기준으로 유지한다.
