# VoiceBox 5800X GPU 배치 · 70% 자동 재생 개발

- 일시: 2026-08-15
- 범위: Dell StoryMaker V1 + 5800X `F:\VoceBox` VoiceBox 전용 엔진
- 목적: 문장 단위 순차 생성 대신 Qwen CustomVoice GPU 배치 생성, 약 70% 준비 시 브라우저 자동 재생 시작

## 변경 사항

### 5800X VoiceBox
- `backend/backends/qwen_custom_voice_backend.py`
  - `generate_batch()` 추가
  - Qwen `generate_custom_voice()`에 text/language/speaker 리스트를 전달해 실제 GPU batch 추론
- `backend/models.py`
  - `BatchGenerationRequest` 추가, 최대 4문장
- `backend/routes/generations.py`
  - `POST /generate/batch` 추가
  - 각 batch 결과를 개별 WAV/generation으로 저장
  - GPU OOM은 HTTP 507로 반환해 클라이언트가 작은 batch로 재시도 가능
- `start-voicebox.ps1`
  - PowerShell이 Python stderr INFO 로그를 NativeCommandError로 취급해 예약 작업이 종료되는 문제를 발견
  - `$ErrorActionPreference`를 `Continue`로 조정
  - `StoryMaker VoiceBox 5800X` 예약 작업 Running 및 `/health` 정상 확인

### Dell StoryMaker V1
- `storymaker-web/backend/app/api/voicebox.py`
  - `VoiceboxBatchGenerateRequest`와 `/generate/batch` 프록시 추가
- `storymaker-web/backend/app/static/v1/voicebox-studio.js`
  - 최대 3문장 GPU batch 생성
  - 10문장 기준 batch 계획 `3 + 2 + 2 + 3`, 7문장 완료 시 정확히 70% 도달
  - batch 실패 시 자동으로 더 작은 batch로 분할, 최종 1문장은 기존 단일 생성으로 fallback
  - 생성 버튼 클릭 순간 Web AudioContext를 미리 unlock하여 나중의 자동 재생이 브라우저 정책에 막힐 가능성을 줄임
  - 70% 준비 시 앞 청크부터 자동 재생하며 나머지 batch는 계속 생성
  - 전체 완료 후 기존 최종 WAV 자동 병합/저장 유지
- `voicebox-studio.html`
  - 배치/70% 자동 재생 안내 문구 반영
  - JS cache tag `20260815-gpu-batch-autoplay70-1`
