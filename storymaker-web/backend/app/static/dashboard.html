AI가 콘텐츠를 만드는 과정

컴퓨터가 익숙하지 않은 소상공인도 “입력 → 생성 → 확인 → 활용” 순서만 따라가면 됩니다.

1

스토리메이커

글 콘텐츠를 만드는 과정
  1. 1입력하기
    업체명, 지역, 오늘 한 일을 적습니다.
  2. 2AI가 만들기
    블로그, 인스타, 당근마켓 글을 자동으로 만듭니다.
  3. 3확인하고 고치기
    마음에 안 드는 문장만 가볍게 수정합니다.
  4. 4복사하거나 업로드하기
    복사해서 블로그나 SNS에 업로드 합니다.
StoryMaker 바로가기
2

팟캐스트

음성 콘텐츠를 만드는 과정
  1. 1입력하기
    딱딱한 홍보내용을 남녀간의 대화 형식으로 만듭니다.
  2. 2AI가 만들기
    사람이 말하듯 한국어 음성으로 제작합니다.
  3. 3확인하고 고치기
    콘텐츠 분위기에 맞는 소리 구성을 더합니다.
  4. 4복사하거나 업로드하기
    MP3 파일로 내려받거나 공유에 활용합니다.
Podcast 바로가기
3

슬라이드쇼

영상 콘텐츠를 만드는 과정
  1. 1입력하기
    현장 사진이나 상품 사진을 올립니다.
  2. 2AI가 만들기
    이미지, 음성, 자막을 결합해 영상으로 만듭니다.
  3. 3확인하고 고치기
    9:16 세로형 영상으로 제작해 모바일에 맞춥니다.
  4. 4복사하거나 업로드하기
    유튜브 쇼츠, 인스타 릴스 등에 활용합니다.
