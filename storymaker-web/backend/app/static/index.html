업체 페르소나 작성 가이드✕ 닫기

1. 업체 정체성

업종, 활동 지역, 경력, 자격·기술을 적습니다. 예: “울산에서 30년간 주택 보수를 해 온 생활밀착형 집수리 전문가”.

2. 주요 고객과 문제

누구를 돕고 어떤 문제를 해결하는지 씁니다. 예: “노후 주택 누수와 욕실 파손으로 급한 40~60대 자가 거주 고객”.

3. 말투와 글의 방식

친근함·전문성·문장 길이·설명 순서를 지정합니다. 예: “현장 경험이 드러나는 존댓말, 문제→원인→시공→관리법 순서”.

4. 차별점과 신뢰 요소

당일 대응, 직접 시공, 견적 원칙, 보증, 실제 사례 등 경쟁 업체와 다른 점을 구체적으로 적습니다.

5. 핵심 키워드 입력법

쉼표로 구분해 지역+서비스 중심으로 5~15개를 권장합니다. 예: “울산 집수리, 북구 누수 수리, 욕실 리모델링, 타일 교체, 긴급 보수”. 같은 뜻의 과도한 반복은 피합니다.

6. 전화번호

고객에게 공개할 대표 연락처를 입력합니다. 지역번호 또는 휴대전화 번호를 하이픈과 함께 정확히 확인해 주세요.

7. 포함·금지 표현

브랜드 문구, 연락 유도 방식과 함께 과장 표현·가격 단정·경쟁사 비방처럼 사용하지 않을 표현도 명시합니다.

작성 예시

“울산 북구에서 30년간 집수리와 욕실 리모델링을 직접 시공한 전문가다. 누수나 타일 파손으로 불편한 자가 거주 고객에게 원인과 해결 과정을 쉬운 존댓말로 설명한다. 현장 상태, 작업 과정, 사후 관리 팁 순서로 쓰며 ‘빨리박사 오박사’ 문구를 자연스럽게 사용한다. 확인되지 않은 최저가·무조건·완벽 같은 과장 표현은 쓰지 않는다.”
