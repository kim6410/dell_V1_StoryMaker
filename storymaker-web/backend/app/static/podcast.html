이 안내는 StoryMaker 팟캐스트 생성기에서 사용하는 Supertonic 기반 음성 합성 모델과 관련된 라이선스 주의사항 입니다.

1. 적용되는 라이선스

AI 모델, Hugging Face 배포 모델: OpenRAIL-M License가 적용될 수 있습니다. Hugging Face에 올라온 음성 합성 모델 데이터, ONNX 파일, 모델 가중치 등에는 일반 오픈소스와 다른 책임 있는 AI 사용 조건이 붙습니다.

2. 상업적 사용 가능 여부

OpenRAIL-M 계열 라이선스는 상업적 사용 자체를 무조건 금지하는 형태가 아닙니다. 다만 서비스를 운영하거나 앱, 웹서비스, 제작툴에 포함해 사용할 때는 아래의 책임 있는 사용 조건을 지켜야 합니다.

3. 반드시 피해야 하는 사용

  • 타인을 속이기 위한 딥페이크 음성 제작
  • 사기, 보이스피싱, 허위 사실 유포 목적의 음성 생성
  • 타인의 명예를 훼손하거나 특정인을 사칭하는 콘텐츠 제작
  • 동의 없는 개인정보, 민감정보, 음성 특징을 악용하는 사용
  • 불법 행위, 악의적 자동화, 사회적 피해를 유발할 수 있는 사용

4. 서비스 운영 시 고지 의무

이 사이트에 제작되어 서비스 되는 팟캐스트 생성기 모델은 Supertonic 기반이며 OpenRAIL-M의 사용 제한 조항을 준수합니다.

5. StoryMaker에서의 권장 고지 문구

이 서비스의 일부 음성 합성 기능은 Supertonic 기반 AI 음성 모델을 사용할 수 있습니다.
사용자는 타인을 사칭하거나 속이는 목적, 불법적 목적, 명예훼손, 허위정보 유포, 동의 없는
개인정보 악용 목적으로 음성을 생성해서는 안 됩니다.

6. 실무 운영 팁

  • 고객용 서비스라면 이용약관 또는 안내 페이지에 AI 음성 사용 고지를 넣는 것이 안전합니다.
  • 상업 콘텐츠 제작은 가능하더라도, 특정 실존 인물의 목소리를 흉내 내는 방식은 피하는 것이 좋습니다.
  • 광고, 블로그, 숏폼, 팟캐스트 제작에 사용할 때는 “AI 음성으로 제작됨” 또는 “AI 음성 합성 기능 사용” 안내를 상황에 맞게 넣는 것을 추천합니다.
  • 모델 파일이나 파생 모델을 재배포하는 경우에는 원 라이선스 조건을 함께 전달해야 합니다.
